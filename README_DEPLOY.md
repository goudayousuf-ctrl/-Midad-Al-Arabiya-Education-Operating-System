# نشر مداد العربية AI على Vercel

## البنية النهائية (متكاملة)
- `index.html` — الصفحة التسويقية العامة (نقطة الدخول عند فتح الرابط الرئيسي مباشرة)
- `madad_v2_unified.html` — التطبيق الفعلي بكل بواباته التسع (لوحة القيادة، الطالب، المعلم، القرآن، الإشراف، الإدارة، المناهج، التواصل، التقارير)
- `api/index.py` — دالة Python واحدة (FastAPI) تغطي كل نقاط النهاية السبع
- `requirements.txt` / `vercel.json` — إعداد النشر

## كيف يعمل التكامل
كل زر وكل بطاقة بوابة في `index.html` يشير مباشرة إلى `madad_v2_unified.html#اسم_القسم`
(مثال: `madad_v2_unified.html#quranPanel`). عند فتح هذا الرابط، تتجاوز صفحة التطبيق
شاشة تسجيل الدخول تلقائيًا وتفتح القسم المطلوب مباشرة ومُفعّلًا في القائمة الجانبية —
جرّبت هذا فعليًا بمتصفح حقيقي قبل التسليم.

## خطوات النشر
1. ارفع كل ملفات هذا المجلد إلى مستودع GitHub جديد (رفع مباشر من المتصفح، بلا أوامر git).
2. من لوحة Vercel: Add New -> Project -> اختر المستودع.
3. **قبل الضغط على Deploy**: أضف من Environment Variables:
   - Key: `GEMINI_API_KEY`
   - Value: مفتاح Gemini API الخاص بك
4. اضغط Deploy. الصفحة التسويقية ستكون على الرابط الرئيسي، والتطبيق على `/madad_v2_unified.html`.

## ملاحظة أمان
لا تضع مفتاح GEMINI_API_KEY داخل أي ملف كود مطلقًا — فقط داخل Environment Variables في لوحة Vercel.
